# 任务模板 · 防乱找路 & 防呆（2026-09-21）

> 用法：把下面【开工约定】粘到任务描述最前面（让新会话照抄即可），
> 能显著减少"开局乱找路"的浪费步数，并避免误碰登录/支付。

【开工约定】
1. 第一步：**立即 Launch 目标App**（示例：美团=com.sankuai.meituan；腾讯视频=com.tencent.qqlive；大众点评=com.dianping.v1）。
2. 在目标App出现前，**禁止**：按 Back、回桌面、点其他图标、进入微信/QQ等无关应用。
3. 若屏幕上已经是目标App，直接继续任务，不要重复启动。
4. 遇到"登录 / 验证 / 支付"页面：**立即停下、如实报告**，不要自行尝试登录或支付。
5. 不要关闭系统弹窗/权限弹窗（保持现场，如实报告）。
6. 每次操作后等待 1–2 秒再判断下一步，避免连点与过早点按。

（本模板与"抢跑哨兵"是双保险：哨兵负责自动预启动，模板负责兜底防乱找路。）

## 附：视频 / 测试类任务口径（防误拒）

当任务是「验证虚拟屏 / 自动化能不能操作某内容 App」（如抖音切换视频）时，**别用“刷”字**（容易被读成“刷量”类平台违规而拒做），按这个口径说：

> 【本机自有设备 · 自动化技术验证，只验证操作是否生效】
> 请用虚拟屏打开抖音（com.ss.android.ugc.aweme），依次上滑切换 5 条视频；
> 不点赞、不评论、不收藏、不下载、不保存、不主动互动；
> 完成后报告：切换了几条、每次操作是否生效。

（口径三件套：去敏感关键词 + 声明测试背景 + 划清操作边界。）
