1. **改前**：跑 hc.sh + 备份目标文件（backup_20260920/，加日期后缀）

## kill / 重启进程规范（2026-09-20 补充）
- 禁用“裸 pattern”直接 kill（ps | /system/bin/grep xxx | awk '{print $2}' | xargs kill）：pattern 可能匹配到当前命令自身（其命令行含目标字样）→ 命令被自杀（exit 143）。
- 正确三步：①列出候选（pattern 带行尾锚 $ 或精确形态）→ ②核对 PID 数与身份 → ③逐个 kill 后 ps 复核。
- 单实例守护（如 watcher）重启规范：先数实例数 → >1 先杀多余（保留 1 个）、=0 再启动 → 启动后必须复核“实例数==1”。
- 案例：23:11 重启 v5 时 pattern 自匹配导致命令被误杀 + 产生双实例；已按上述流程修复（现保留单实例 21114）。
